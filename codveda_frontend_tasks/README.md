Each level is kept in a separate folder. The projects are intentionally simple enough to understand, customize, and explain in a video.

## Run Level 1
Open each `index.html` directly in a browser.

## Run Level 2
```bash
cd level-2-spa-api
npm install
npm run dev
```

The React project uses Vite, React Router, and the browser Fetch API.

## Level 3
Open `index.html` in a browser. The animation demo uses GSAP from a CDN.
For the performance task, run Lighthouse in Chrome DevTools before and after optimization and record the results.
